# PRD: 독서 기록앱 (MVP)

## 1. 개요

읽은 책과 읽고 싶은 책을 등록하고, 독서 상태와 기록(메모/리뷰)을 관리하는 개인용 독서 기록 서비스. MVP는 도서 검색·등록, 독서 상태 관리, 기록 작성, 독서 현황 확인이라는 핵심 흐름만 지원한다.

## 2. 기능 명세

| 기능 ID | 기능명 | 설명 |
|---|---|---|
| F001 | 로그인/회원가입 | 이메일/비밀번호 기반 가입 및 인증 |
| F002 | 도서 검색 | 제목/저자 키워드로 도서 검색 |
| F003 | 도서 상세 조회 | 검색된 도서의 상세 정보(제목, 저자, 표지 등) 조회 |
| F004 | 내 서재에 추가 | 도서를 내 서재에 등록(초기 상태: 읽고싶음/읽는중/완료 선택) |
| F005 | 내 서재 목록 조회 | 내 서재에 등록된 도서를 상태별로 조회 |
| F006 | 독서 상태 변경 | 등록된 도서의 상태(읽고싶음/읽는중/완료) 변경 |
| F007 | 독서 기록 작성 | 도서별 메모/리뷰 작성 |
| F008 | 독서 기록 조회 | 도서별로 작성된 메모/리뷰 목록 조회 |
| F009 | 독서 현황 요약 | 상태별 도서 수(읽고싶음/읽는중/완료) 요약 확인 |

## 3. 메뉴 구조

```
로그인/회원가입 (F001)
└─ 홈 (F009)
└─ 도서 검색 (F002)
   └─ 도서 상세 (F003)
      └─ 내 서재에 추가 (F004)
└─ 내 서재
   ├─ 서재 목록 (F005)
   └─ 서재 도서 상세
      ├─ 독서 상태 변경 (F006)
      └─ 독서 기록 (F007, F008)
```

## 4. 페이지별 상세

### 4.1 로그인/회원가입 페이지
- 관련 기능: F001
- 구성: 이메일/비밀번호 입력, 로그인 버튼, 회원가입 링크
- 액션: 인증 성공 시 홈으로 이동

### 4.2 홈 페이지
- 관련 기능: F009
- 구성: 상태별(읽고싶음/읽는중/완료) 도서 수 요약
- 액션: 요약 항목 클릭 시 내 서재 목록(F005, 해당 상태 필터)으로 이동

### 4.3 도서 검색 페이지
- 관련 기능: F002
- 구성: 검색어 입력창, 검색 결과 리스트(제목, 저자, 표지)
- 액션: 결과 항목 클릭 시 도서 상세(F003)로 이동

### 4.4 도서 상세 페이지
- 관련 기능: F003, F004
- 구성: 도서 정보(제목, 저자, 표지, 설명), 내 서재 추가 버튼 및 초기 상태 선택
- 액션: 추가 완료 시 내 서재 목록(F005)으로 이동

### 4.5 내 서재 목록 페이지
- 관련 기능: F005
- 구성: 등록 도서 리스트, 상태별 필터(읽고싶음/읽는중/완료)
- 액션: 행 클릭 시 서재 도서 상세 페이지로 이동

### 4.6 서재 도서 상세 페이지
- 관련 기능: F006, F007, F008
- 구성:
  - 도서 기본 정보
  - 독서 상태 변경 영역(F006)
  - 독서 기록 작성 폼(F007)
  - 작성된 독서 기록 목록(F008)
- 액션: 상태 변경/기록 저장 시 즉시 반영, 변경 사항은 홈(F009)에 자동 집계
