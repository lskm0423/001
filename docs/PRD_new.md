# PRD: 프로젝트 리소스 관리 서비스 (MVP)

## 1. 개요

여러 프로젝트의 계획(작업, 인력 배정)을 등록하고, 실제 투입된 리소스(인력/시간)를 기록하여 계획 대비 실적을 비교·확인할 수 있는 관리 서비스. MVP는 프로젝트/작업 등록, 인력 배정, 실적 입력, 계획 대비 실적 비교, 대시보드 확인이라는 핵심 흐름만 지원한다. 인증은 MVP 범위에서 제외한다.

## 2. 기능 명세

| 기능 ID | 기능명 | 설명 |
|---|---|---|
| F001 | 프로젝트 등록 | 프로젝트명, 설명, 기간(시작일/종료일) 등록 |
| F002 | 프로젝트 목록 조회 | 등록된 프로젝트를 목록으로 조회 |
| F003 | 작업(Task) 등록 | 프로젝트 하위 작업 등록(작업명, 계획 기간, 계획 투입 시간) |
| F004 | 작업 목록 조회 | 프로젝트별 작업 목록 조회 |
| F005 | 팀원 관리 | 팀원 등록/조회(이름, 역할) |
| F006 | 인력 배정 | 작업에 팀원을 배정(배정 기간, 배정 시간) |
| F007 | 실적 투입 기록 | 팀원이 작업에 실제 투입한 시간을 일자별로 기록 |
| F008 | 계획 대비 실적 비교 | 작업/프로젝트 단위로 계획 투입 시간과 실제 투입 시간을 비교 |
| F009 | 일정 조회 | 프로젝트 내 작업 일정을 타임라인(간트 형태)으로 확인 |
| F010 | 대시보드 | 전체 프로젝트의 진행률, 리소스 소진율(실적/계획 비율)을 요약 확인 |

## 3. 메뉴 구조

```
대시보드 (F010)
└─ 프로젝트 목록 (F002, F001 등록)
   └─ 프로젝트 상세
      ├─ 작업 목록 (F004, F003 등록)
      │  └─ 작업 상세
      │     ├─ 인력 배정 (F006)
      │     └─ 실적 투입 기록 (F007)
      ├─ 일정 (F009)
      └─ 계획 대비 실적 (F008)
└─ 팀원 관리 (F005)
```

## 4. 페이지별 상세

### 4.1 대시보드 페이지
- 관련 기능: F010
- 구성: 프로젝트별 카드(진행률, 리소스 소진율), 전체 리소스 소진율 요약
- 액션: 프로젝트 카드 클릭 시 프로젝트 상세로 이동

### 4.2 프로젝트 목록 페이지
- 관련 기능: F002, F001
- 구성: 프로젝트 리스트(이름, 기간, 상태), 프로젝트 등록 버튼/폼
- 액션: 등록 완료 시 목록에 즉시 반영, 행 클릭 시 프로젝트 상세로 이동

### 4.3 프로젝트 상세 페이지
- 관련 기능: F004, F003, F009, F008
- 구성:
  - 프로젝트 기본 정보
  - 작업 목록 및 작업 등록 폼(F003, F004)
  - 일정 타임라인 뷰(F009)
  - 계획 대비 실적 요약(작업별 계획/실제 투입 시간, 차이)(F008)
- 액션: 작업 등록 시 목록·일정에 즉시 반영, 작업 행 클릭 시 작업 상세로 이동

### 4.4 작업 상세 페이지
- 관련 기능: F006, F007, F008
- 구성:
  - 작업 기본 정보(계획 기간, 계획 투입 시간)
  - 인력 배정 영역(팀원 선택, 배정 시간 입력)(F006)
  - 실적 투입 기록 폼 및 목록(일자, 팀원, 실제 투입 시간)(F007)
  - 계획 대비 실적 비교(계획 시간 vs 누적 실제 시간)(F008)
- 액션: 배정/실적 저장 시 즉시 반영, 변경 사항은 프로젝트 상세·대시보드에 자동 집계

### 4.5 팀원 관리 페이지
- 관련 기능: F005
- 구성: 팀원 리스트(이름, 역할), 팀원 등록 폼, 팀원별 배정 현황 요약
- 액션: 등록 완료 시 목록에 즉시 반영
