# PRD: Technical Readiness Planner for Abatement Development Project (MVP)

## 1. 개요

감축(Abatement) 개발 프로젝트에서 적용하려는 기술의 준비도(Technical Readiness)를 등록·평가·관리할 수 있는 플래너 서비스. MVP는 프로젝트/기술 등록, 준비도 평가, 체크리스트 관리, 결과 확인이라는 핵심 흐름만 지원한다.

## 2. 기능 명세

| 기능 ID | 기능명 | 설명 |
|---|---|---|
| F001 | 로그인 | 이메일/비밀번호 기반 사용자 인증 |
| F002 | 프로젝트 등록 | 감축 개발 프로젝트 신규 등록(명칭, 개요 입력) |
| F003 | 프로젝트 목록 조회 | 등록된 프로젝트를 리스트로 조회 |
| F004 | 프로젝트 상세 조회 | 특정 프로젝트의 기본 정보 및 하위 항목 조회 |
| F005 | 감축 기술 등록/관리 | 프로젝트에 적용할 감축 기술 항목 등록·수정·삭제 |
| F006 | 기술 준비도(TRL) 평가 입력 | 기술별 준비 단계(TRL) 값 입력 및 수정 |
| F007 | 준비도 체크리스트 관리 | 기술별 준비도 점검 항목 등록 및 완료 여부 체크 |
| F008 | 준비도 요약 대시보드 | 프로젝트/기술별 준비도 현황을 한눈에 확인 |
| F009 | 코멘트 작성 | 기술 또는 체크리스트 항목에 코멘트(메모) 작성 |

## 3. 메뉴 구조

```
로그인 (F001)
└─ 대시보드 (F008)
└─ 프로젝트 관리
   ├─ 프로젝트 목록 (F003)
   ├─ 프로젝트 등록 (F002)
   └─ 프로젝트 상세 (F004)
      ├─ 감축 기술 목록 (F005)
      ├─ TRL 평가 (F006)
      ├─ 준비도 체크리스트 (F007)
      └─ 코멘트 (F009)
```

## 4. 페이지별 상세

### 4.1 로그인 페이지
- 관련 기능: F001
- 구성: 이메일/비밀번호 입력, 로그인 버튼
- 액션: 로그인 성공 시 대시보드로 이동

### 4.2 대시보드
- 관련 기능: F008
- 구성: 프로젝트별 감축 기술 준비도(TRL) 요약 목록
- 액션: 항목 클릭 시 해당 프로젝트 상세로 이동

### 4.3 프로젝트 목록 페이지
- 관련 기능: F003
- 구성: 등록된 프로젝트 리스트(명칭, 등록일)
- 액션: 신규 등록 버튼(F002 페이지 이동), 행 클릭 시 상세 이동(F004)

### 4.4 프로젝트 등록 페이지
- 관련 기능: F002
- 구성: 프로젝트 명칭, 개요 입력 폼
- 액션: 저장 시 프로젝트 목록으로 이동

### 4.5 프로젝트 상세 페이지
- 관련 기능: F004, F005, F006, F007, F009
- 구성:
  - 프로젝트 기본 정보(명칭, 개요)
  - 감축 기술 목록 섹션(F005): 기술 추가/수정/삭제
  - 기술별 TRL 평가 섹션(F006): 기술 선택 후 TRL 값 입력
  - 준비도 체크리스트 섹션(F007): 점검 항목 추가 및 완료 체크
  - 코멘트 섹션(F009): 기술/체크리스트 항목별 코멘트 입력
- 액션: 각 섹션 저장 시 즉시 반영, 변경 사항은 대시보드(F008)에 자동 집계
